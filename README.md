# README

## 背景
この動画([https://www.youtube.com/watch?v=wce2AKl-KkM](https://www.youtube.com/watch?v=wce2AKl-KkM))を見て自分もコマンドプロンプト上での3Dレンダリングをやってみようと思った。

## 言語
C言語

## 開発環境及び動作環境
- Windows 11
- Visual Studio 2022

## 共通解説
文字の高速描画やキー入力のために windows.h の関数を用いた。

自機の向きや位置の決定→画面文字バッファの計算→コマンドプロンプトへの描画を繰り返す。

## 個別解説
1. **点**

   ソース:[dot.c](dot.c)\
   動画:[https://youtu.be/3CqFe1cMnGY](https://youtu.be/3CqFe1cMnGY)
   
   空間上に位置する点を画面上に投影する。

   コマンドプロンプトの各文字位置に対応する角度範囲にもし点が存在したらその文字位置には'+'を表示し、存在しなかったら空白文字を表示する。

   自機の回転はすべての点を逆向きに回転することで、自分自身の並行移動はすべての点を逆向きに平行移動させることで実現した。

   キー操作で回転運動と並行運動が加速または減速する。

   - S/D : ヨーイング
   - F/G : ローリング
   - H/J : ピッチング
   - K/L : 前進と後退

   自機の並行移動を感じられるように、ドーナツ状の点群を置いた。

   背景には Hipparcos Main Catalog にある上位4096個の明るい星を貼り付けた。背景は回転はするが、並行移動はしない。

1. **ボクセル**
   
   ソース:[boxel.c](boxel.c)\
   動画:[https://youtube.com/shorts/zhCqvp_l99k](https://youtube.com/shorts/zhCqvp_l99k)

   空間上に位置する立方体を画面上に投影する。

   コマンドプロンプトの各文字位置に対応するベクトルを自機の目線に沿って空間に向けて発射し、もし立方体に当たったらその文字位置では空白以外の文字を表示する。表示する文字はどの方向の面にベクトルが当たったかで決める。(ソースではこの判定を`trace`関数で行う。)
   
   自機の回転はすべての点を逆向きに回転することで、自分自身の並行移動はすべての点を逆向きに平行移動させることで実現した。

   キー操作で回転運動と並行運動が加速または減速する。

   - S/D : ローリング
   - F/G : ヨーイング
   - H/J : ピッチング
   - K/L : 前進と後退

   自機が立方体に衝突したら跳ね返るようにした。

1. **ポリゴン**
   
   ソース:[polygon.c](poylgon.c)\
   動画:[https://youtube.com/shorts/qWu5L2hKYMA](https://youtube.com/shorts/qWu5L2hKYMA)

   空間上に位置する三角形を画面上に投影する。

   各三角形に対して、コマンドプロンプトの各文字位置に対応するベクトルを自機の目線に沿って空間に向けて発射し、もし当たったらその文字位置では空白以外の文字を表示する。表示する文字は三角形ごとに決めている。(ソースではこの判定を`trace`関数で行う。)

   複数の三角形が見た目上重なったときはZバッファ法を用いてどれを表示するかを決める。(ソースでは`buff.z`配列がその方角での最も近い三角形までの距離を収める。)

   キー押下で回転運動と並行運動が開始する。キーを離すと停止する。

   - S/D : ローリング
   - F/G : ピッチング
   - H/J : ヨーイング
   - K/L : 前進と後退
